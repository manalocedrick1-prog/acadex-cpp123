Privacy Policy

Last updated: October 17, 2026

Acadex is a student task organizer created as an academic project. This policy explains how the current version handles information.

1. Information collected

Acadex does not ask for an account, name, email address, location, or other identifying information. Users may enter task titles, subject names, dates, priorities, task types, and notes. Do not enter passwords, sensitive personal information, or confidential records.

2. How information is stored and used

Task entries are stored in the local storage of the browser on the device being used. The entries are used only to display and organize tasks within this browser. Clearing browser data or using a different browser/device may remove or make the entries unavailable. This version does not provide cloud synchronization or a remote database.

3. Sharing and third parties

The current app does not send task entries to a developer-operated server. The website is hosted on GitHub Pages, which may process standard technical information such as IP addresses, requests, and server logs under GitHub's own privacy policies. Acadex does not use analytics, advertising, cookies for tracking, or any other third-party service. If hosting or app features change, this policy will be updated to describe those changes accurately.

4. Data deletion

Users can delete individual tasks in the app. Users can also clear the browser's site data to remove locally stored tasks. Deleting site data may also remove other website preferences.

5. Security and limitations

Browser local storage is not a secure vault and should not be used for sensitive information. Anyone with access to the same browser profile may be able to view the stored tasks. Use a personal device and avoid confidential details.

6. Children's privacy

This academic organizer is not designed to collect personal information from children. Users should avoid entering identifying or sensitive information.

7. Contact

For privacy questions about Acadex, email the student developer, Rhod Cedrick Manalo, at REPLACE_WITH_YOUR_EMAIL. The website itself has no contact form and does not collect or store your email address.

About Acadex

A lightweight web app for student productivity.

Problem it addresses

Students often manage deadlines across class announcements, notes, and messaging applications. Acadex provides one simple place to record tasks and check progress.

Project objectives

  • Organize academic tasks and deadlines.
  • Help users identify pending and overdue work.
  • Show progress through a simple dashboard.
  • Provide a responsive interface and a clear privacy policy.

How to use it

  1. Open My Tasks and fill in a title and due date.
  2. Choose the subject, priority, and task type.
  3. Save the task, then mark it complete when finished.
  4. Use search and filters to find tasks.
